## Rationale

The 9-step fresh terminal sequence in §III Rule 3 was authored before POSSESSIO_v2.sol's V4 hook architecture required HookMiner for CREATE2 salt mining. Uniswap removed `lib/v4-periphery/src/utils/HookMiner.sol` from upstream main. The Uniswap Foundation's canonical resolution is to install `akshatmittal/hookmate` and run `npm install` inside it to populate `node_modules/@uniswap/v4-periphery/`, where HookMiner now resides.

This amendment updates the canonical sequence from 9 steps to 13 steps, adding hookmate install and npm install. The expanded sequence has been verified working: produces clean compile of `MineHookSalt.s.sol` and preserves the 487/487 test baseline.
