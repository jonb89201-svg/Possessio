How we work

Four rules, followed on every build.

  1. Nothing is claimed until a test confirms it. If it isn't proven, we don't say it.
  2. Every test run is kept, failures included.
  3. A test that can't fail is a defect. We prove each one by planting a break it has to catch.
  4. Every version is reviewed cold, by a reviewer starting fresh.

Possessio is built by one developer, John Byars, with the best AI models of the day. He runs every build, test and deploy himself, from a phone.

Security review

An independent security firm, KupiaSec (Kupia Sec Enterprise), has agreed to review our payment contracts before they launch. Under that agreement, KupiaSec receives a share of each launch fee.

Until that review is done, we don't call the contracts audited. They are open source under the MIT license, so anyone can read them now.
